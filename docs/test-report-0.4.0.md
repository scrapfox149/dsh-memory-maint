## 四、发现并修掉的问题

| 问题 | 修法 |
|---|---|
| **`mem.py` 不在 `selftest.legacy`** | 它是转发器（把 `--selftest` 当动作名），加进白名单 |
| **自测检查误把 `py-core/` 当命令脚本** | 检查时排除 `py-core/`（契约层是库，不是命令） |
| **`check-memory-refs` 报 6 个假红** | 根因是**记忆正文里抄了错误路径**（第三次犯），去掉目录前缀后清零（43 个引用 / 0 失效） |
| **`docs/CONFIG.md` 的过时说明**（「`tools` 要重启」） | 同步文档时改成「1 秒轮询，即时生效」 |

| 项 | 说明 |
